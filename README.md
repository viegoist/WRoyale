## 🌟 Öne Çıkan Detaylı Özellikler

- ⚡ **Büyü & İçerik Akışı (Social Feed):** 
  - Gönderi oluşturma, kategori bazlı etiketleme (Duyuru, Proje, Düşünce, Oyun).
  - Canlı Beğeni, Inline Yorum Sistemi ve Bağlantı Paylaşımı.
- 💬 **Sihirdar Meclisi (Canlı Sohbet & DM Drawer):** 
  - Sağ alt köşede açılıp kapanabilir direct message (DM) sohbet penceresi.
- ⚙ **Tam Kapsamlı Canlı Profil Düzenleyici:** 
  - Sayfa yenilenmeden isim, rol, avatar, profil detayları ve sosyal medya bağlantılarını `LocalStorage` ile canlı değiştirme.
- 🎨 **Dinamik Dark / Light Tema Modu:** 
  - Tek tıkla açık/koyu tema geçişi ve göz yormayan modern Glassmorphism tasarım.
- 👥 **Sihirdar Loncası (Guild Widget) & Gündem Hashtag'leri:** 
  - Aktif üyeler, trend başlıklar ve takip önerileri sağ barda dinamik olarak sergilenir.
- 🎮 **Wizard Royale Arcade Canvas Oyunu:** 
  - Saf JavaScript Canvas API ile hazırlanmış mini survival oyunu.
- 💾 **JSON Veri Yedekleme:** 
  - Tüm profilinizi ve akış paylaşımlarınızı JSON dosyası olarak indirip saklayabilirsiniz.

## 🚀 GitHub Pages Üzerinde Yayınlama Rehberi

Projenizi ücretsiz ve hızlı bir şekilde canlıya almak için şu basit adımları izleyin:

1. **GitHub Reposu Oluşturun:**
   - [GitHub](https://github.com) hesabınıza giriş yapın.
   - **New Repository** butonuna tıklayın.
   - Repo adınızı yazın (Örn: `wizardroyale` veya `kullaniciadi.github.io`).

2. **Dosyaları Yükleyin:**
   - İndirdiğiniz paketteki `index.html`, `favicon.svg` ve `README.md` dosyalarını reponuza ekleyin (`Add file > Upload files`).

3. **GitHub Pages özelliğini açın:**
   - Reponuzun **Settings** (Ayarlar) sekmesine gidin.
   - Sol menüden **Pages** seçeneğine tıklayın.
   - **Branch** kısmını `main` (veya `master`) yapıp `/ (root)` seçeneğini belirleyin ve **Save**'e basın.

4. **Tebrikler! 🎉**
   - Siteniz birkaç dakika içinde `https://kullaniciadi.github.io/wizardroyale` adresinde canlıya geçecektir!
